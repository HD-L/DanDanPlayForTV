# 弹弹 TV：独立重写产品规格

更新日期：2026 年 10 月 13 日。

## 目标与证据边界

重新构建一个首先服务电视遥控器的个人视频与弹幕播放器。使用者坐在沙发上，用方向键、确定、返回和媒体键找到媒体、开始观看、续播、选轨、调整弹幕字幕并处理故障；需要输入文字时扫码在手机浏览器填写。成功标准是完整观看流程顺畅，而不是页面数量或对旧实现的逐项模仿。

仅从父项目 README 和产品文档提取能力，不阅读旧实现。文档未定义的旧行为、数据库和加密规则不作兼容保证。新项目拥有独立包名、存储和构建，可与旧应用共存。

现有文档确认：本地及局域网、FTP、WebDAV 视频；双内核切换；弹幕自动匹配、搜索、下载、样式和屏蔽；字幕自动匹配、搜索、下载、外挂字幕及字号、描边、颜色调整；每周番剧、搜索和详情；HTTP 远程播放控制、弹幕远程配置、云屏蔽与简繁转换。旧 README 明确账号接口已关闭、Torrent 下载未完成，原远程控制文档没有媒体投送及设备发现契约。

本文件定义产品目标和行为边界，不保存“首版未实现”快照。原产品能力、用户补充要求和可选扩展的来源核对见 [需求核对](需求核对.md)，实际实现、验证证据与缺口见 [功能状态](功能状态.md)。补齐原文明确功能是交付要求，调整规格不能代替补齐实现。

## 实现原则

采用独立领域模型、来源适配器和播放会话，以 TV 使用流程重新实现，选用公开第三方播放器与标准协议库。不得读取、复制或链接旧工程实现、资源、数据库模型和构建脚本。

UI 技术可选用原生 Android View、Compose for TV 或满足交互契约的其他实现。播放采用可切换的 Media3 与 VLC 后端，保持双内核提高兼容性与故障恢复的原产品目标；不绑定旧产品的 IJK/EXO 名称。后续可替换或增加后端，验收以实际行为为准。

## 信息架构

- 继续观看：最近进度、快速打开、媒体源入口；没有历史时直接引导添加媒体。
- 媒体库：本地目录、网络地址、WebDAV、SMB、FTP；逐级浏览、侧载字幕弹幕、播放队列、收藏、扫描索引及搜索过滤。
- 番剧：每周更新、季度浏览、关键词搜索、简介与剧集；番剧信息不等于提供视频版权资源。
- 设置：播放、弹幕、字幕、屏蔽、服务凭证、远程配对、数据管理、能力说明。

导航入口保持少而稳定。媒体播放后回到原目录和原焦点。番剧不抢占启动体验。无内容时不给空白页或假的推荐。

## TV 交互契约

| 场景 | 操作与验收 |
| --- | --- |
| 启动 | 首个可执行控件获得焦点；所有操作都有一致的可见边框、颜色和尺度反馈 |
| 页面切换 | 侧栏选择页面，右方向进入内容；返回先恢复导航，再返回首页，首页返回退出，不弹出强制确认 |
| 列表 | 上下移动并滚动；确定进入目录或播放；中文、长名称和空目录仍可操作 |
| 播放画面 | 控制栏隐藏时确定播放/暂停并显示控制栏，上下只显示控制栏；媒体播放暂停键直接控制；隐藏时左右快退快进，显示时方向键移动焦点 |
| 播放返回 | 先关闭设置或控制栏，再退出播放器并保存进度；不留下后台声音 |
| 输入 | 所有需要键盘的文本统一用手机浏览器填写。每次操作生成专属表单网页，TV 显示标题、二维码、地址与取消按钮，手机提交后回到当前操作；页面结束后不自动转到下一表单。返回取消、离页/切集撤销、过期提交拒绝。数字选项与开关仍可遥控选择，密码及密钥不回传网页 |
| 异步加载 | 页面保留可返回控件；过期请求不得覆盖新页面；失败显示原因及重试/修改配置入口 |
| 列表更新 | 用稳定媒体 ID 恢复焦点；数据重排时选择邻近有效项；不无限追抢焦点 |

遥控器验收覆盖 TV 模拟器；正式发布验收还需真实设备上的不同遥控器、弱性能盒子、音频中断、HDMI 和系统文件选择器。

## 完整功能范围

### 媒体来源与媒体库

本地通过系统目录授权读取视频和同目录字幕弹幕，支持持久授权、中文目录、权限撤回提示。直接打开 HTTP/HTTPS 视频及 HLS/DASH 链接。WebDAV 使用 PROPFIND 列目录，认证请求可直接交给播放器；SMB 与 FTP 通过独立读取适配器支持浏览和随机定位。网络账号不放入展示地址或日志。

添加媒体源直接在 TV 展示本次操作的二维码，手机专属表单选择来源类型、名称、地址及必要凭据。选本地目录时隐藏地址与网络凭据，提交后由 TV 系统选择器授予目录读取权限；选择不需要认证的类型时隐藏账号密码。类型由服务端允许值校验，字段必填规则随类型变化，隐藏字段不参与保存；手机无法替电视完成系统文件授权。

目录内视频组成队列，上一集/下一集不依赖文件名推测；支持自然排序、文件名过滤、收藏、目录扫描建立真实索引及跨目录搜索。扫描须可取消，并显示运行、完成、失败和达到预算的状态；部分索引不能冒充完整扫描结果。来源修改、删除以及连接失败必须可恢复。SFTP、NFS、DLNA 和服务器自动发现可以作为独立扩展，不与 FTP/SMB 混称，也不计入旧产品已承诺能力。

### 播放

实际播放本地和网络媒体，具有准备、缓冲、暂停、播放、结束、失败状态；续播、快进快退、倍速、音轨/字幕轨、画面比例、队列切集。释放播放器前保存进度；切后台暂停，返回后可恢复。根据设备解码能力播放，不承诺所有编码或无条件 4K/HDR。解码失败提供重试与原因，不伪报“自动切内核成功”。

双内核需实际接通解码后端。播放中和失败页都允许换内核，切换时释放旧后端，保留媒体、位置、播放意图、倍速、音量和可恢复的轨道/字幕设置，不建立重复播放会话。不同后端需通过相同的生命周期、选轨、定位和远程命令验收；后端不支持的格式或来源应明确提示并提供可用选择。

### 弹幕

支持本地 XML 和开放平台弹幕；滚动、顶部、底部，显示开关、字号、透明度、速度、描边、显示区域、同屏上限、关键字和正则屏蔽。无效正则返回错误，不影响视频。弹幕以媒体时间为时钟，暂停、倍速、seek 和切集后同步，密集数据有可控预算。

屏蔽正则的实现须避免误写表达式卡住播放线程；语法差异在输入时明确告知。弹幕筛选、可见数量和输入规模使用可控预算，超密集窗口不能无界扫描。具体正则库、规则条数、字符数、窗口和同屏上限属于实现配置，可根据设备与性能证据调整，不作为永久产品限制。

自动匹配根据官方文件指纹/名称协议；不能对无法获得大小或无法随机读取的来源发送假的文件哈希。失败时允许手动搜索并选择剧集、下载弹幕或关闭弹幕。云屏蔽和简繁转换来自原远程配置说明，应使用真实数据服务及转换字典，说明服务条件；本地屏蔽不能冒充云屏蔽，未转换的文本不能报告转换成功。

### 字幕

内嵌字幕通过播放器选轨；外挂 SRT、WebVTT、ASS/SSA 及 TTML 由实际支持的解码器处理；同名文件优先关联，另可手工选择。支持字幕延迟、字号、文字色和描边调整，并为 TV 设置安全边距。文件自带 ASS 样式与用户样式的优先级应明确展示。支持自动识别及手选文字编码，失败时提供重新选择入口；支持导入 TTF/OTF 字体，并通过 VLC 原生渲染处理 ASS 样式与媒体中的字体附件。具体特效、字体附件、编码和格式需有真实样本验收，不能据库接口宣称全面兼容。

在线字幕自动匹配、搜索、下载是原产品明确功能。使用 OpenSubtitles 正式 API 完成凭证配置、搜索、下载和缓存；用户自己的 API Key、账号、配额与服务条款作为外部条件。自动匹配仅在可真实读取文件大小和首尾片段、服务返回唯一可靠的文件指纹结果时下载；名称候选由用户确认，不能把名称相近当可靠自动匹配。允许直接导入字幕文件或字幕地址，服务不可用时展示原因和恢复路径。字幕提供方可替换，能力验收不绑定具体类名。

### 番剧与弹弹play 服务

使用官方 API 完成每周番剧、搜索、详情、季度列表与季度筛选、剧集匹配和弹幕下载。遵守应用鉴权要求。没有开发者 AppId/AppSecret 时给出明确配置说明，不发匿名请求反复报错。应用级凭证不等于用户登录；旧项目已关闭的账号接口不计为可恢复的既有功能。若新增账号能力，应另行确定可用服务和产品契约。

开发者凭证加密保存，系统自动备份与默认公开备份不包含秘密；用户明确选择的密码加密备份按数据管理契约处理。面向公众分发时可通过自建代理保存签名密钥；在客户端持有密钥无法保证不被提取。不得将测试凭证提交到版本库。

### 远程控制与投送

根据用户在 2026 年 10 月 12 日的补充与纠正要求，应用启动时自动准备局域网 Web 服务，使用随机配对令牌及二维码。所有媒体源名称/地址/账号/密码、视频和附件链接、搜索词、开发者凭证、关键词与正则规则都采用手机表单，不保留 TV 软键盘路径。每次操作生成 `/input/{sessionId}?token=…` 专属地址，扫码页面只显示该操作需要的字段，不汇集其他输入参数或遥控器。整张表单一次提交，成功、取消或过期后显示结束，不自动跟随电视后续输入。下一次操作生成新的表单 ID 和二维码。

遥控器首页 `/` 独立于输入页面。所有网页 API 使用 Bearer 令牌鉴权，未配对的静态网页不含表单、凭证或播放状态。令牌保存在当前标签页的 sessionStorage 中，刷新或打开新的专属路径可复用令牌，但不会改变页面绑定的输入请求。网页控制与 TV 控制进入同一播放会话，支持状态、缓冲信息、播放暂停、相对/绝对定位、倍速、音量、停止/退出、弹幕配置及媒体 URL 投送。弹幕配置覆盖显示类型、样式、显示区域与数量、屏蔽和语言选择，并与 TV 设置即时一致。关闭服务后释放端口、取消待输入并撤销旧连接；重新配对生成新令牌和二维码。下次需要输入时自动重新开启服务。服务属于应用进程，不保证 Android 后台永久保活。

输入请求单独有不可预测的 ID 和十分钟有效期，成功只消费一次。返回、离开页面、切集或退出取消旧请求，旧地址不能读取或提交其他输入请求。已存密码/密钥不下发到网页，只告知是否已保存，留空可保留，显式清除才能删除；手机校验错误保留表单继续编辑。网页轮询和提交始终绑定专属表单 ID，迟到响应不得恢复已结束输入或覆盖用户正在填写的内容。

手机与电视需处于同一可信局域网。使用 HTTP 时应明确告知传输未经过 TLS 加密；配对令牌代表输入与遥控权限，应只交给可信设备。可在保持表单和会话契约的前提下增加更强的配对或传输保护。

新版使用 `/api/input`、`/api/status`、`/api/control`、`/api/config`、`/api/open` 等独立接口。旧协议缺少 AES 细节，不能声称兼容旧加密鉴权；保留 `/init` 版本入口也不代表实现旧 `/remote/control`。如需要旧协议适配，应独立验收。镜像投屏与设备自动发现可独立扩展；旧文档中的亮度字段需针对可控制的设备能力定义语义，不支持时明确返回原因，不能回报假成功。

### 设置、数据与隐私

设置和进度独立保存；账号、网络秘密使用 Android Keystore 加密。历史、收藏和索引可清除，媒体源可删除，敏感字段不出现在错误、配对页面和公开备份中。备份使用显式版本化格式：公开备份排除凭据，用户明确选择的密码备份可加密携带网络凭据和开发者密钥，本机 Keystore 密钥不导出，在线字幕服务凭证不进入备份。备份保存来源、设置、收藏、索引、观看进度及剧集绑定，不打包视频和字幕文件。导入先验证并展示替换摘要，用户确认后原子替换，失败不清空原数据；本地目录授权需在目标 TV 重新取得。旧数据库迁移器可以另行增加，与运行时隔离，且必须先有样本和契约。

本项目不需要广告标识符、手机号、手机状态、定位和通讯录权限，不收集观看文件内容。日志仅用于设备本地调试。更新、崩溃上报和统计需未来单独引入且写入隐私说明。

### 可独立扩展的方向

NFS、SFTP、DLNA、设备自动发现、Android TV Watch Next、手机端文件转发、旧数据库迁移、下载队列、磁链解析与 Torrent 引擎可以在明确需求后扩展。旧 README 的模块介绍提及磁链解析，并将 Torrent 下载标为未完成；这些不能被误报为旧版已可用能力，也不能据此要求新 TV 工程恢复停用账号。新增方向不冻结现有模型、界面技术或模块结构。

双内核、在线字幕、字幕样式、云屏蔽及简繁转换等已有文档依据的能力仍属于前文完整范围，未实现或未验证时应在功能状态中报告具体缺口。无障碍名称、焦点与可读反馈属于 TV 操作质量要求；语音系统集成和 Watch Next 需各自验收，不将平台扩展与基础焦点可用性混为一谈。

## 架构与变更自由度

`core` 为纯 Kotlin 规则：媒体与来源、进度、播放键状态机、弹幕筛选时间线、字幕解析。它不引用 Android、网络、数据库和播放器具体实现。

`app/data` 负责来源协议、加密持久化、开放平台服务及播放器数据源；通过明确的数据模型供界面调用。`app/player` 持有一个播放会话及其生命周期，调度媒体时钟、轨道、字幕与弹幕。`app/ui` 定义页面、焦点及表单请求，提交后继续当前操作；`app/remote` 通过 RemoteHub 共享应用级服务，由 PhoneInputBroker 管理输入会话、二维码及取消，网页请求通过鉴权后交给表单协调或播放会话。

依赖方向为 UI/远程 → 应用协调 → 数据与会话 → core。后续替换 View、Media3、网络库或存储不要求重写领域规则。避免全局可变播放器、跨模块事件总线、把所有配置放进一个巨型页面、用旧数据库结构冻结新模型。

技术版本、类名、目录与模块数量属于实现选择，不是长期产品限制。行为契约、清晰的依赖职责和兼容验收是新增实现的约束；按实际独立发布、测试和替换需求调整模块，不为未知需求预建通用插件系统。

## 错误与性能验收

- 网络和磁盘不在 UI 线程；退出页面忽略过期返回；关闭会话取消定时任务和异步任务，释放播放器与会话网络资源。无法即时取消的底层读取使用有限超时，并在功能状态中说明边界；切集不被旧附件网络任务占住。
- 网络连接、读取和远程命令具有超时；凭据错误与服务不可用分开呈现。
- 外部 XML 禁止外部实体；限制远程请求、弹幕和字幕输入大小；异常文件不崩溃。
- 弹幕只处理当前时间窗口和有限可见项，不逐帧扫描整部视频评论。
- 续播定位限制在有效媒体时长内；未知时长不伪造百分比；结束状态不把完成的视频强行续播到结尾。
- 程序退出、Home 键、换集、暂停、快速 seek 和外部控制不得导致重复播放器或失步。

## 验证与交付

交付中文功能规格、架构说明、独立构建命令、功能状态与真实限制；产出可安装 APK。自动化覆盖导航状态、播放定位、字幕时序、无效正则与弹幕时间线、凭证/来源校验和协议边界；网页测试直接运行应用内 JavaScript，验证专属地址绑定、结束状态、条件字段与迟到响应。TV 模拟器使用真实方向键验证焦点、返回、扫码入口、播放及续播，手机网页验证完整填写与提交。公网 API 使用正式凭证验证，同时验证未配置时的错误路径；具体已通过范围与外部条件记录在功能状态中。

独立性验收要求：在临时目录仅复制 `tv-rewrite/` 后可以构建，源码无父目录引用、旧包名、旧模块和旧资源依赖。能力状态表必须与代码、构建和实际测试证据一致；规则测试通过不等于正式字幕服务、真实 NAS 或设备兼容已经通过。
