# 原版功能清单与 TV / 手机归属讨论

整理日期：2026-10-24。依据：父工程 4.1.4 源码（`app`、`anime_component`、`local_component`、`storage_component`、`player_component`、`user_component`、`common_component`、`data_component`），包括配置表（`*ConfigTable.kt`）、路由表、各页面 Activity/ViewModel、布局与字符串资源、菜单、`document/ScreenCasting.md` 以及 `change/` 版本记录。与现有 `需求核对.md` 不同，本文是**逐功能从源码抽取**的清单，目的是和 TV 重写（`功能状态.md` 中 0.2.0 的能力）逐项对照，讨论每一项的去留与操作端。

表格列说明：

- **原版行为**：源码里实际存在的功能与可配置项。
- **输入类型**：遥控器能否直接完成。`选择`＝方向键+确定即可；`文本`＝需要键盘输入；`手势`＝依赖触摸；`系统`＝依赖系统选择器/权限。
- **TV 重写现状**：对照 `功能状态.md`。`有`＝已接入；`缺`＝未接入；`替代`＝用别的方案实现了同类目标。
- **建议归属**：`TV`＝遥控器直接操作；`手机`＝手机网页（表单或遥控页）；`丢弃`＝不做；`待定`＝需要讨论。建议只是我的初始意见，请逐项确认。

### 磁链引擎可行性核对

- `repository/thunder/thunder.aar`（约 4.8 MB）内含 `arm64-v8a` 与 `armeabi-v7a` 的 `libxl_thunder_sdk.so` 等 4 个库，无 x86；初始化仅需 `XLTaskHelper.init(context)`，不需要账号或密钥。
- 流程：磁链 → `addMagnetTask` 下载种子（5 秒超时）→ 解析种子得到文件列表 → 选中视频 → `createPlayTask` 边下边播，播放地址为本地文件路径；缓存目录可清理，DHT 开关与最大任务数为可配项。
- 限制：Android TV 模拟器为 x86，无法测试磁链功能，必须实体盒子验收；闭源 SDK，问题只能绕不能修。

## 12. 海报墙 → 磁链 → 在线播放：流程草案

### 12.1 海报墙（TV）

- 数据来源：弹弹play `bangumi/shin`（每周）、`bangumi/season/anime/{year}/{month}`（季度）、`search/anime`（搜索），每条带 `imageUrl`、标题、评分、放送状态。TV 重写已接通这三个接口，海报墙只改展示层。
- 布局：横向按星期/季度分组的封面网格；焦点项放大并显示标题、评分、更新到第几集；长按或"菜单"键进入该番剧详情。
- 本地状态叠加：关注标记、已看集数（来自本地追番/已看数据），封面角标提示"有新集"。

### 12.2 番剧详情 → 剧集 → 找资源

1. 详情页剧集列表每一集提供两个动作：**播放本地关联记录**（已有）与 **找资源**。
2. "找资源"用 `番剧名 + 集数` 自动拼关键字调搜索节点 `/list`，结果列表按字幕组/分类可筛选（遥控器点选），显示文件大小、发布日期、字幕组。
3. 关键字不准时，用手机表单改关键字重搜（原版"分词"功能由手机打字替代，不做）。
4. 搜索节点地址：设置 → 资源搜索节点，手机表单填写；未配置时"找资源"按钮提示去配置。

### 12.3 磁链播放（TV）

1. 选中一条资源 → 下载种子 → 展示种子内文件列表（多集合集时让用户选文件）→ 创建播放任务 → 进入播放器。
2. 播放器显示下载速度 / 已缓冲百分比；缓冲不足时显示等待而不是报错。
3. 播放记录：记录磁链 hash + 文件索引 + 关联 episodeId，下次从详情页或"继续观看"可直接续播；种子缓存保留，视频缓存按容量上限自动清理。
4. 弹幕：播放前按文件 hash 自动匹配；匹配失败时因为已知 episodeId，直接拉该集弹幕，不再要用户搜索。这是磁链流程相对普通文件的优势。
5. 字幕：合集内同名字幕优先；否则按射手 hash 匹配。

### 12.4 手动磁链入口（手机）

- 媒体库 → "磁链视频"来源：手机表单粘贴磁链或上传 `.torrent`；历史列表在 TV 上展示并可续播、删除。

### 12.5 需要新增/修改的配置

| 配置 | 操作端 |
|---|---|
| 资源搜索节点地址 | 手机 |
| DHT 开关、最大同时任务数 | TV |
| 磁链缓存目录容量上限、立即清理 | TV |
| 默认字幕组 / 分类偏好（可选） | TV |
